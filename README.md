# Containment Breach

A small run and gun browser game. A scientist ninja chases Professor Emeritus Jabroni through three levels to recover a stolen vial of Cryptobacter.

## Play

Open `index.html` in a browser. There is nothing to install and no server needed.

Controls are shown on the title screen and can be remapped under CONTROLS.

Nothing in this game is laboratory safety advice. In particular, never mix bleach with guanidine thiocyanate.
